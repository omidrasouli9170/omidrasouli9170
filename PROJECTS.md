# Project Archive

This file is a public, non-confidential index of projects I have built, designed, operated, or materially worked on. It is intentionally written at product/system level. Source code, credentials, private repositories, customer data, internal infrastructure details, and proprietary implementation logic are not published.

## AI, Knowledge Systems & Intelligent Workflows

### 1. CortexIS Core
AI-assisted neuroscience knowledge and workflow platform. The system turns specialist reference material into searchable semantic knowledge and supports controlled retrieval, reporting, case-oriented workflows, and AI-assisted interaction. The public description deliberately excludes private retrieval architecture, prompts, infrastructure addresses, and internal data design.

### 2. CortexIS Patient App
Patient-facing conversational application designed to connect users to the CortexIS environment through a simpler interaction layer. The project focuses on guided interaction, knowledge access, controlled responses, and separation between user-facing experience and the private core platform.

### 3. QEEG Brainmap Platform
Platform for brain-map case workflow, knowledge access, educational reporting, and structured case handling. It is part of the broader neuroscience knowledge-system work and is presented publicly only at product level.

### 4. QEEG Knowledge Builder
Knowledge-ingestion and preparation system for QEEG, EEG, Neurofeedback, and related specialist reference material. The goal is to transform source material into structured, searchable knowledge suitable for controlled retrieval and downstream reporting.

### 5. AirtimeForge
Broadcast workflow automation product. Work includes operational foundations for media inspection, exact timing, catalog/import flows, matching, settings, and structured broadcast-oriented workflows. The repository and implementation remain private; this archive records the product and the problem space.

### 6. WhatsApp Business Agent
Messaging automation system for sales and customer-intake workflows. It captures conversations, identifies intent and interest, collects structured fields such as contact details and requirements, applies follow-up rules, stops when a contact opts out, and hands complex questions to a human operator.

### 7. Site Builder / Landing Factory
Automated website-provisioning workflow built around structured customer input. The concept connects intake, theme/site selection, content collection, provisioning, deployment, and handoff so that repeatable sites can be delivered quickly without rebuilding the operational process for every customer.

### 8. Custom CRM Systems
A family of purpose-built CRM and operations systems rather than one generic CRM. The work focuses on translating each business's real workflow into pipelines, records, statuses, actions, messaging, handoff, and exception handling.

### 9. WordPress by Omid
Custom WordPress control and management layer for websites that use highly customized front ends. The project supports direct content/page import, client-facing editing, custom settings, controlled login/administration, and maintaining WordPress as the CMS without forcing the public site to look like a standard theme.

### 10. MCP WordPress / WP Agent
Agent-oriented WordPress workflow for performing controlled site/content operations through structured tools rather than manual dashboard work. The project explores safe automation of repeatable WordPress management tasks.

### 11. Apparel Lead Discovery
Lead-discovery and qualification workflow focused on apparel businesses. The system is intended to identify potential businesses, enrich useful information, classify leads, and prepare them for structured outreach or follow-up.

### 12. Instagram Album Importer
Workflow for importing selected content from public social pages into websites without requiring customers to manually duplicate the same gallery. The concept includes periodic or manual refresh and detection of newly available public content.

### 13. Veydic
Web platform with administration and reporting workflows. Work around the project includes the website layer, admin/report engine, operational status, release risks, and practical maintenance/delegation structure.

### 14. CRM UI-First Prototyping Framework
A project-delivery method implemented as a reusable product workflow: design the full login, navigation, screens, states, and end-to-end user journey first, then connect backend capabilities module by module. The approach helps both customer and builder understand the final system before expensive backend work is completed.

## Infrastructure, Hosting & Delivery

### 37. Restricted-Egress Infrastructure

## Publication Policy

This archive records project experience, not source-code availability. A project appearing here does **not** mean its repository is public. Private repositories, internal design documents, credentials, customer information, server addresses, sensitive network topology, proprietary prompts, algorithms, and security-sensitive configuration are deliberately excluded.

Project dates are not backfilled artificially. Where an original project date is not documented with confidence, the archive leaves the date out rather than presenting the date it was added to GitHub as the date it was originally built.
